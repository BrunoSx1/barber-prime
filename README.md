
# Barber Prime — Barbearia Premium

Projeto demonstrativo de um website moderno e responsivo
para uma barbearia premium.

O objetivo é apresentar uma experiência visual elegante,
aliando design, acessibilidade e interatividade.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- CSS Flexbox e Grid
- Intersection Observer API

## Funcionalidades

- Layout responsivo
- Menu mobile interativo
- Galeria de fotografias ampliável
- Animações durante a rolagem
- Cards de serviços e preços
- Agendamento via WhatsApp (configurável)
- Navegação acessível
- SEO básico
- Favicon personalizado

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra index.html no navegador ou utilize Live Server.

## Configuração do WhatsApp

No arquivo script.js, localize:

const WHATSAPP_NUMBER = "";

Insira o número autorizado do estabelecimento
no formato 55 + DDD + telefone.

Enquanto não houver número configurado,
o site funciona em modo demonstrativo.
